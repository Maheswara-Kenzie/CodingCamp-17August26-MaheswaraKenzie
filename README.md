# Expense Tracker
Repository ini berisi **Personal Financial Tracker**, web pencatat pengeluaran yang saya buat untuk tugas *Coding Camp RevoU*. Projek ini mengimplementasikan keterampilan pengembangan web saya untuk menghadirkan solusi praktis dalam mengelola keuangan pribadi secara intuitif.

## Fitur Utama

-  **Pencatatan Transaksi:** Tambah, edit, dan hapus data pengeluaran serta pemasukan.
-  **Kategori Transaksi:** Mengelompokkan transaksi (makanan, transportasi, hiburan, dll.).
-  **Ringkasan & Visualisasi:** Menampilkan total saldo, total pengeluaran, dan grafik alokasi keuangan secara *real-time*.
-  **Desain Responsif:** Tampilan optimal di perangkat *mobile* maupun *desktop*.
-  **Penyimpanan Lokal:** Data tersimpan secara otomatis menggunakan `localStorage` browser.

---

## Tech yang Digunakan

- **HTML5** – Struktur halaman web
- **CSS3 / Tailwind CSS** – Styling dan tata letak responsif
- **JavaScript (ES6+)** – Logika interaktif dan manipulasi DOM
- **Git & GitHub** – Version control dan repositori kode

## Cara Menjalankan Projek

1. **Clone repository ini:**
   ```bash
   git clone https://github.com/username-kamu/personal-financial-tracker.git
   ```

2. **Masuk ke direktori projek:**
   ```bash
   cd personal-financial-tracker
   ```

3. **Buka file `index.html` di browser kamu**, atau gunakan extension **Live Server** di VS Code untuk pengalaman yang lebih baik.
